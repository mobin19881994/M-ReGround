M-ReGround - Central Settings Information
=========================================

Purpose
-------
This project already keeps static app settings in one central file:
lib/config/app_config.dart

If you want to change app behavior, edit ONLY that file.

How to keep static values in one file
-------------------------------------
1) Open: lib/config/app_config.dart
2) Keep values as: static const
3) Use values everywhere in code as: AppConfig.<settingName>
4) Do not hardcode duplicate values in other files

Example
-------
In app_config.dart:
  static const int appExpiryDays = 30;

In any service/screen:
  final days = AppConfig.appExpiryDays;
